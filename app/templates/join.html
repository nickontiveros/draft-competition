1 · Get your credentials

If you're playing on Kalshi
  1. Log in at kalshi.com (the website, not the app).
  2. Open Account → Settings → API Keys (kalshi.com/account/profile).
  3. Click Create API key. When asked for permissions/scopes, select read-only — do NOT enable trade or withdraw. The tracker only ever reads your balance and bets.
  4. Kalshi shows a Key ID and downloads a private key file (.pem / .key / .txt). Keep the file — Kalshi won't show it again.
  5. Below: paste the Key ID as your identifier, and open the key file in any text editor and paste its full contents (starts with -----BEGIN) into the private key box.
If you're playing on Polymarket
  1. Open Polymarket and go to your profile (tap your avatar).
  2. Copy your wallet address — it starts with 0x… (on the profile page, tap the address to copy it).
  3. That's it — it's public info, no keys needed. Paste it as your identifier below.
  4. Heads-up: some accounts created in the US iOS app don't show up in Polymarket's public data yet. If your bankroll reads $0.00 after joining despite having funds, ask the organizer to check — you may need to play on Kalshi instead.
